# 远程求职向世界 · 实战手册（开源）

面向中文用户的「如何面向全世界 remote 求职」开源指南。

现有的远程工作平台（Remote OK、We Work Remotely、Upwork…）只解决**「去哪找」**，
很少有人教**「怎么真的拿下全世界的远程工作」**。本项目把方法论开源，
任何人都能用、能改、能提 PR 补充。

## 内容

- 📘 **实战手册** —— `playbook.html`
  按角色选平台、竞争力三件套、申请打法、落地避坑、冷启动 5 件事。
- 📊 **平台借鉴分析** —— `analysis.html`
  10 个主流平台定位图 + 从 levelsio/awesome-remote-job 提炼的可借鉴打法。
- 💡 **求职实战 tips** —— `tips.html`
  两份小红书案例转写（简历过 ATS 机筛 / LinkedIn 主动找 remote）+ 共性总结。
- 📰 **媒体报道与研究报告** —— `参考资料/media-reports/`
  收录关于远程工作的权威媒体深度报道与学术研究（HBR、FT、The Economist 等），持续更新。
- 💼 **Upwork 专题** —— `参考资料/upwork专题/`
  收录 Upwork 出海接单相关的实战内容（小红书等渠道筛选），持续更新。
- 💼 **中文远程岗位（筛选）** —— `参考资料/中文远程岗位/`
  从小红书等中文渠道筛选的远程/自由职业岗位信息，附来源、日期与申请方式，持续更新。
- 🌍 **海外工作资源** —— `参考资料/海外工作资源/`
  各国官方/权威求职平台与海外工作渠道整理（如瑞典 Arbetsförmedlingen），附真实数据与门槛提示，持续更新。

- 🏆 **远程求职故事** —— `参考资料/远程求职故事/`
  真实 remote 求职成功经历、关键决策与可复用方法，持续更新。
- 🎯 **求职战略（系统方法论）** —— `参考资料/求职战略/`
  地狱级市场拿多个 offer 的 6 件事（早开始 / 收窄目标 / 全面准备 / 失败当信息 / 行业认知补经验 / 选对雇主）+ 底层逻辑「把求职当项目管」；附 remote 求职映射。与简历 / LinkedIn / 谈薪串成完整作战链。
- 📝 **简历专题** —— `参考资料/简历专题/`
  AI 简历 Skill 避坑锐评（从夯到拉）+ 反幻觉简历工作流 + 跨来源合成的「简历红线清单」。
- 🌐 **LinkedIn 主页优化（中英双语）** —— `参考资料/linkedin-profile-4changes.md`
  4 个显著提升 HR 回复率的 LinkedIn 主页改动（头像 / Headline / About / Featured），附英文翻译，适合留学生·外企·remote 求职。
- 🧭 **个人品牌与定位** —— `参考资料/个人品牌与定位/`
  AI 时代「如何呈现自己」的认知框架（战略层）：裸能力 < 公开 Claim ≤ AI 增强交付力；与简历专题 / LinkedIn 优化互补。
- 💰 **谈薪水（薪资谈判）** —— `参考资料/谈薪水/`
  HR 内部视角的谈薪实战：把 HR 当盟友、薪资天花板由「不可替代性的感知」决定；报薪资结构 / 把"我要"变"我给" / 给 HR 递台阶。与 remote·跨境谈薪的关联。
- ✉️ **求职信 Cover Letter** —— `参考资料/求职信CoverLetter/`
  高分 cover letter 写法（以英国求职为样本）：一页 A4 / 四段结构（开头·对齐 JD·为什么是这家·结尾）/ 英式签名格式 / 六个雷区；映射到面向全世界找远程工作（针对性更关键、PDF 铁律、签名看市场）。与简历专题呼应：简历过机筛、求职信过人筛。

## 本地查看

直接双击 `index.html`，或起一个本地服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
