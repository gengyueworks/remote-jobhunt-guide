远程求职向世界 · 实战手册

不是"去哪找远程工作"，而是"怎么真的拿下全世界的远程工作"。

核心心智：别把"远程求职"当成一个网站（Remote OK / LinkedIn）。把全世界当成你的招聘市场——你是面向全球雇主的销售，平台只是你触达他们的渠道之一。

一、按角色选平台（别瞎投，先定位）

你的角色优先平台为什么
技术 / 工程Remote OK、We Work Remotely、AngelList、Stack Overflow Jobs、Hacker News「Who is hiring」、LinkedIn（远程筛选）技术岗全球需求最大、薪资透明、远程接受度最高
设计 / 创意Dribbble Jobs、Behance、Working Nomads、Remote OK（Design 类）、Upwork作品集驱动，靠视觉作品说话，平台重作品不重简历
文案 / 内容 / 传媒Upwork、Fiverr、Contently、LinkedIn、各类 newsletter / 社区（如 NODESK）任务制/项目制多，适合从副业切入再转长期
运营 / 增长AngelList、Remote OK、We Work Remotely、Working Nomads初创公司远程运营岗多，AngelList 直达创始人
想广撒网Google Jobs「remote」、Indeed（远程筛选）、各类 aggregator聚合全网，做信息源而非主战场

注：你已有的聚合 demo 就该放在这一层——它负责把上面这些源汇成一条流，省去每天挨个刷。

二、全球化竞争力三件套（没有就先补）

  • 英文 Profile：LinkedIn + 一份英文简历 + 一个个人站（哪怕一页）。雇主第一眼看的是英文表达是否专业。
  • 公开作品 / 轨迹：GitHub、Dribbble、写作、案例。远程招聘"看不见人"，作品就是你的信用。
  • 时区可用性声明：明确写"我能在 XX–YY UTC 实时协作 / 或全异步"。这是全球雇主最关心的隐性门槛。

三、申请打法（比投简历有效 10 倍）

  • 冷启动定向 outreach：在 AngelList / LinkedIn 找到正在招人的创始人/招聘官，用 3 句话说明"我能解决你哪个具体问题"，附作品。比海投响应率高得多。
  • 被看见混对社区：Nomad List、r/remotejs、NODES、各类 Slack/Discord。很多远程岗"不挂出来"，只在社区里口口相传。
  • 内容用 awesome list / 聚合做信息源：把 levelsio 那种清单当雷达，每天扫新增，抢早期窗口。
  • 杠杆从副业切长期：先用 Upwork / Fiverr 接一个项目证明能力，再谈长期合作或转正。

四、落地避坑（全球化特有，最容易翻车）

  • 合同形态：全职雇佣（难，需工签）/ 独立 contractor（最常见，你对自己负责）/ 通过 EOR（名义雇主，如 Deel、Remote.com）拿正式雇佣但不受限。
  • 收款：Wise、PayPal、Deel。先确认雇主用哪个，别等到发薪才发现提现被卡。
  • 税务：你是哪国税务居民，就按哪国报税。contractor 收入通常自己申报，别假设"海外收入不用管"。
  • 时区：明确 async 还是实时。能接受 4 小时重叠的岗位，竞争激烈度低很多。
  • 薪资基准：用 Remote OK 的薪资透明帖、levelsio 的公开数据校准预期，别按国内行情报价。高才报高、低就别硬撑。

五、冷启动：今天就能做的 5 件事

  • 把 LinkedIn 改成英文，开"Open to remote work"，地区设成目标国。
  • 整理一份能公开看的作品/案例（GitHub / 网盘 / 个人站），链接放 Profile 置顶。
  • 在 AngelList 或 LinkedIn 找出 10 个正在招人的远程团队，写 10 条定向 outreach。
  • 注册 Upwork / Fiverr，发一个你最能打的服务页（哪怕先接小单）。
  • 订阅 1–2 个远程招聘 newsletter（Remotive、NODES、Daily Remote），当每日雷达。
这手册既是你个人的求职导航，也能成为以后平台的内容飞轮——教人"怎么干"的内容，比职位列表本身更能聚人和做 SEO。下一步可深化：按你的具体角色（技术/设计/传媒）出一份更细的战术页。
