## 简历红线清单（跨来源合成）

把上面所有来源的共同底线抽成一张清单——**写简历前、中、后各过一遍**：

### 写之前：态度红线
- [ ] **不编数据**。任何“估算 / estimate / 自动量化”出来的数字，背调一问就翻车（锐评 · ResumeSkills / resume-quantifier 反面教材）。
- [ ] **只写真实经历**。每条要点对应你实际做过的事，AI 只是帮你表达，不是帮你发明（简历一条龙 · 特色 1）。
- [ ] **每岗定制，别海投**。同一份简历群投不同公司，面试率会崩（荷兰故事：1% vs 15–20%）。

### 写之中：内容红线
- [ ] **数字来源分级**。测过的 / 记不清的 / 只有范围没比例的 / 完全没有，四类不同写法（简历一条龙 · 特色 2）。
- [ ] **拆分个人 vs 团队贡献**。出现“我们”时追问哪部分是你做的（简历一条龙 · 特色 3）。
- [ ] **用 STAR / XYZ 改写**。场景·动作·判断·结果·量化，五项齐了才合格（简历一条龙 · 对话采集）。
- [ ] **过 ATS**。纯文本友好、无花哨图表，并从 JD 提取关键词嵌进经历（tips · 案例一）。

### 写之后：压测红线
- [ ] **自己答一遍面试追问**。每条 bullet 自问“这数怎么测的 / 基线是什么 / 你做的还是 mentor 定的”，答不上来的当场改（简历一条龙 · 压测清单）。
- [ ] **用 AI 做内容体检**。让 AI 生成每条要点的可能追问，答不上的标出回改（简历一条龙 · 内容体检；可衔接模拟面试）。
- [ ] **选工具看证据闸门**。优先带“质量闸门 / 证据分级”的 Skill，远离只做润色和套模板的（锐评排名）。
