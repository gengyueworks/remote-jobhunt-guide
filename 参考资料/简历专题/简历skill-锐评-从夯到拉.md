## 逐条详评

### 🥇 get-job.skill（又名 实习.skill，中文全流程求职 skill）· 281 星
- **6 个里唯一让作者服气的**。它不是帮你“润色”简历，是**先扒目标岗位的 JD，再反过来改你的经历描述**，对齐的是 HR 看人时真正看的点。
- 改完作者自己读了一遍：“是我会想约面的那种简历。”
- 两道保险：
  - **开工前“开天辟地”**：缺材料直接告诉你缺什么，**不自己补**；
  - **交付前“质量闸门”**：一条条核对每个 claim 的证据等级，**不过红线不交付**。原话“证据占字数”不是嘴上说，是真有闸门卡着。
- 中文场景最完整（岗位匹配→投递追踪全流程），2026-07 还在更新。流程偏重，但简历这种“一次翻车终身有痕”的东西，值得。

### 🥈 LLMInternSkill · 265 星
- 大模型实习专用，秋招冲刺期还在更新。
- 专一，只做实习简历但做透了。整个赛道里罕见地给简历**每一行打五档**：可以写 / 谨慎写 / 补证据后写 / 不能写 / 无法判断。
- 示例明说：“没有训练日志和 checkpoint 时，不写‘训练大模型’。”
- 学生党直接冲——它知道没经验的人该怎么写项目。265 星不大，但每一星都是正在投大模型实习的人。
- 缺点：职场老人用不上，所以差夯半档。但它不帮你写得漂亮，**帮你写得诚实**——这点赛道里是稀缺品。

### 🥉 resume-tailoring-skill · 654 星
- 针对 JD 定制简历的“老牌选手”。
- 思路对（按岗位定制），执行差点意思。置信度打分、透明 gap 提示、每一步要你手动确认才继续——工程化态度最认真，README 一直强调 “maintaining factual integrity”，确实做到了。
- 但改出来的东西**方向对但毛糙**，你得自己再顺一遍。当你的**草稿工具**可行；但秋招兵临城下时它停更了 5 个月，ATS 规则和模板时效性是个问号。
- 654 星说明它曾很能打，但缺席了整个秋招，可惜。适合有基础、愿意自己再顺一遍的人，不适合交稿即投。

### NPC · ResumeSkills · 1492 星（赛道第一）
- 20 个 skill 的求职全家桶，星数赛道第一。
- 毛病就是**套模板**：你喂什么经历都给你整成同一种“负责了什么、取得了什么”的八股文。HR 一天看八百份这种，你的就是第八百零一。
- 最爱营销：宣称“面试数翻 25 倍”，这个量化承诺零证据。子 skill `resume-quantifier` 更离谱——明说数字不知道时可以“estimate”，**这就是教你在简历上编数据，背调一问就翻车**。还有“75% 简历……”的说法，也是没有任何出处的伪统计。
- 1492 星说明它最会吹嘘，但没人在为“写了假话被拆穿”负责。06-19 更新。

### NPC · career-ops-plugin · 460 星
- fork 来的二手求职插件。JD 打分、简历定制、自动填表，9 个 skill 广而浅。宣称“任何行业通用”，基本等于哪个行业都不深。你喂什么经历都给你整成同一种八股文。
- 更关键：这是 F5 来的**三手项目**，仓库名还挂着 `do-not-fork`，作者自己都没改完。README 自称 “Honest, not inflated”，态度不错，但功能列表唬人、没一个扛得住深挖。07-23 更新。缝合怪里的新奇葩，也就到这了。

### 拉 · proficiently-claude-skills · 318 星
- 商业公司的开源获客橱窗。名字里带 `proficiently`，用起来最不 proficiently。**半年没更新**，承诺写得比谁都大，产出跟直接问裸模型没区别——这是判断一个 Skill 水不水的金标准。
- 更该警惕：开源仓库首页就是**营销引流漏斗**，还要你导入 LinkedIn 联系人做 network scan，把人脉数据交给商业公司。318 星看着像开源社区投票，其实是商业漏斗。**你不是用户，你是线索。**
- 自动填表 + 批量代投，把名声和履历都押在上面，真实风险。别装。

---

## 作者的结论

- **这条赛道，星数和质量是倒挂的。**
- 全家桶在教你“估算数据”；265 星的小项目在教你“哪句话不能写”。
- **装简历 Skill 之前，先问三件事：**
  1. 它教你怎么编吗？
  2. 写出来的经得住背调吗？
  3. 是帮你，还是把你当线索？

## 可复用的行动清单

- [ ] 选简历 Skill 时，**先看它教不教你编数据**（出现 estimate / 自动量化要警惕）。
- [ ] 优先选有“质量闸门 / 证据分级”的（如 get-job.skill、LLMInternSkill），而非只做润色的。
- [ ] 八股文模板类（ResumeSkills、career-ops-plugin）出的简历 HR 一眼疲劳，别直接投。
- [ ] 凡是要求导入 LinkedIn / 人脉数据做“自动投递”的商业 Skill，默认当漏斗，不装。
- [ ] 任何简历数字，准备好“这数怎么测的 / 基线是什么 / 你做的还是 mentor 定的”三连问。
