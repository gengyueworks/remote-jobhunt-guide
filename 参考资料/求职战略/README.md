# 求职战略（系统方法论）

把「求职」当成一个需要系统性管理的项目来打——而不是靠感觉推进的体力活。

## 本板块内容

- [地狱级市场拿多个 offer 的 6 件事](地狱级市场拿多个offer的6件事.md)
  小红书图文转写（7 图 OCR + 校正）。原作者基于美国医药 / mph 求职观察，总结在缩招市场里仍能拿多个 offer 的人做对的六件事：① 早到荒谬程度的开始 ② 收窄目标而非广撒网 ③ 全面准备而非单点极致 ④ 把失败当信息不当结论 ⑤ 用行业认知深度补经验缺口 ⑥ 选对雇主目标。并提炼底层逻辑：**把求职当项目管，用信息和改进对抗情绪**。文末附「对 remote 求职的映射」。

## 和其他板块的关系

个人品牌（战略：定位放多高）→ 简历 / LinkedIn（拿到面试）→ **求职战略（走完流程、拿多个 offer）** → 谈薪水（把价值兑现成数字）。四环串起来就是一份完整的 remote 求职作战链。
