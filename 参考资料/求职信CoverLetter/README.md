## 定位

Cover Letter 是「过人筛」的书面载体：CV 罗列经历，它解释经历为什么满足 JD。
和 `简历专题`（过机筛）、`LinkedIn 优化`（被主动找到）、`谈薪水`（兑现数字）串成完整作战链。

## 红线

- 内容基于公开 how-to 改写，不挂第三方平台源链。
- 不编造经历、不教造假；cover letter 只做「经历 → JD 要求」的真实映射。
